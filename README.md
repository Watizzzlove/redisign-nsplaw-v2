# NSP Law — Prototype (noth.in Inspired Edition)

Интерактивный прототип главной страницы для юридической фирмы **NSP Law** (Некторов, Савельев и Партнеры) в эстетике парижского дизайн-бюро **noth.in**.

## 💎 Концепция и особенности дизайна
1. **Студийный люксовый минимализм (noth.in aesthetic):**
   * Моноширинные акценты (`IBM Plex Mono`), фирменная статусная антиква (`Cinzel`) и чистый `Inter`.
   * Цветовая палитра: глубокий обсидиановый графит (`#07080A`), чистый белый (`#FFFFFF`), нейтральные серые для вспомогательного текста и деликатные микроакценты.
2. **Фирменный физический курсор (`SmoothCursor`):**
   * Плавный курсор на пружинах (`motion/react` spring physics) с вращением по вектору скорости.
   * Динамическое переключение состояний при наведении на интерактивные элементы: пилюля `( explore ↗ )`, `( partner ↗ )`, `( book ↗ )`.
3. **Плавающие виньетки в списке практик (`WorksList`):**
   * Нумерованный список `( 01 )` — `( 04 )`. При наведении на строку практики всплывает карточка-виньетка с ключевой метрикой, которая плавно следует за курсором.
4. **Центральный 3D-образ Фемиды с Parallax Tilt:**
   * Кастомная 3D-скульптура Фемиды из обсидианового мрамора и титана со световой сеткой, плавно наклоняющаяся в 3D-пространстве в зависимости от координат мыши.
5. **Авторский манифест и ростер партнеров:**
   * Секция философии: *«Большинство фирм цитируют законы. Мы создаем прецеденты»*.
   * Ростер лидеров бюро с функцией копирования email в один клик и прямой ссылкой на Telegram.
6. **Кнопка с анимацией скольжения стрелки (`.btn-nothin`):**
   * Капсульная кнопка в стиле noth.in, инвертирующая цвета при наведении.

## 🚀 Запуск проекта
```bash
# Перейти в директорию
cd prototype-nothin

# Запуск dev-сервера с HMR
npm run dev

# Сборка production-билда
npm run build

# Предпросмотр билда
npm run preview
```
